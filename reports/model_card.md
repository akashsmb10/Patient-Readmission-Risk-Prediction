# Model card

## Intended use

Educational benchmark for studying leakage-aware tabular classification on the UCI Diabetes 130-US Hospitals dataset.

## Out of scope

Not for clinical deployment, treatment, diagnosis, discharge planning, risk scoring, or any decision affecting an individual.

## Data and risk

The dataset is historical, de-identified, and sensitive. It includes race, gender, and age. The model excludes race and gender from features, but other variables can still encode inequities. No causal interpretation is supported.

## Evaluation and monitoring

Use only the held-out test metrics generated by `run.py`. A production system would require governance, prospective validation, site-specific calibration, clinical review, monitoring for drift and subgroup harm, privacy controls, and an approved action pathway. This repository does not provide those elements.
